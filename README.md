This is a simple Java console program for CS3354.  
The objective of the program is to build a grocery management system using parallel arrays. You will
manage data across multiple arrays where the same index refers to the same item..

You can:
- View inventory
- Restock an item
- Exit the program

We worked on this as a group using GitHub. Each member used their own branch and merged their work into main.
